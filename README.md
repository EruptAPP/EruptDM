## About

**Erupt DM** is a cross-platform download manager focused on speed and user experience, serving macOS and Windows with a unified solution — from everyday files and browser takeovers to streaming video and BitTorrent.

## Features

- 🚀 **Multi-threaded acceleration** — segmented multi-connection downloads with resume support to fully utilize your bandwidth
- 🎬 **Video downloads** — parses and merges mainstream streaming formats including m3u8/HLS and DASH
- 🧲 **BitTorrent / Magnet links** — built-in BT engine supporting both torrent files and magnet URIs
- 🌐 **Browser integration** — browser extension automatically takes over downloads, with smart detection and whitelist support
- 🔄 **Multi-device sync** — end-to-end encrypted file and task sync across your devices
- 🗂 **Download management** — queue scheduling, speed limits, and categories for a clear overview
