# Contributing to Erupt DM

Thanks for your interest in contributing to Erupt DM!

## How to Contribute

1. **Report bugs**: use the [Bug Report template](.github/ISSUE_TEMPLATE/bug.yml) and keep the `[BUG]: ` title prefix, adding a short description after it.
2. **Suggest features**: use the [Feature Request template](.github/ISSUE_TEMPLATE/feature.yml) and keep the `[FEAT]: ` title prefix, adding a short description after it.
3. **Submit code**: fork the repository → create a feature branch → commit your changes → open a Pull Request.

## Pull Request Requirements

- One PR solves one thing; keep changes focused.
- Write clear commit messages that explain the "why", not just the "what".
- UI copy changes must be synced across all languages (i18n).
- No hardcoded numbers, paths, URLs or version numbers — use constants or configuration.
- Colors must use theme semantic variables; never hardcode color values.
- Verify the affected features locally before submitting.

## Security Issues

Please do **not** report security vulnerabilities through public issues — see [SECURITY.md](SECURITY.md) instead.

## Code of Conduct

By participating in this project you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).
